# SatQuery AI - Orbital Intelligence & Geospatial Investigation Platform

SatQuery AI is an intelligent geospatial analysis system designed to turn natural-language queries into deterministic satellite investigations and change detection workflows.

## Features (Planned)
- FastAPI spatial analysis backend with geodesic calculation engine
- React + Vite interactive GIS console powered by Leaflet
- Temporal satellite imagery comparison (baseline vs. observation)
- Geodesic buffer zones and proximity filtering
- Evidence inspection and printable geospatial incident reports
